O **ContentFlow** é uma plataforma desenvolvida para facilitar o planejamento e o gerenciamento de conteúdos para redes sociais, reunindo em um só lugar ferramentas para organizar publicações e acompanhar o fluxo de produção.

Este repositório contém a landing page oficial do projeto, que centraliza o acesso às suas aplicações.

- **Mobile:** [Acessar repositório](https://github.com/RonyFonseca/ContentFlow-app)
- **API:** [Acessar repositório](https://github.com/RonyFonseca/ContentFlow-API)

## 🛠️ Tecnologias

Esta landing page foi construída utilizando:

- HTML5
- CSS3
- JavaScript

Sem dependências externas ou processo de build.

## 🚀 Executando localmente

1. Clone este repositório:

   ```bash
   git clone https://github.com/RonyFonseca/ContentFlow-Home.git
   ```

2. Entre na pasta do projeto:

   ```bash
   cd ContentFlow-Home
   ```

3. Abra o arquivo `index.html` no navegador.

**Importante:** mantenha a pasta `assets` no mesmo diretório do arquivo `index.html`.

## ☁️ Publicação

Por ser uma aplicação estática, pode ser publicada facilmente utilizando:

- GitHub Pages
- Vercel

Não é necessário configurar build ou instalar dependências.
